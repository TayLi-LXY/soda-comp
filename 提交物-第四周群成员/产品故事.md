# 群成员管理 · 产品故事（基础 + 进阶 + 挑战）

## 这个功能给谁用？

在**数据分析会话**里编排协作 Agent 的人（会话发起方 / 管理者）。

## 解决什么问题？

群设置抽屉里「添加 / 移出」原先是空壳。本产品与 DeepSeek 不同：一次会话有任务目标，会沉淀可复用的 **Agent**；这些 Agent 可以被**检索并编进其他会话**继续协作。用户需要看清「当前会话有哪些 Agent、从哪次历史会话来」，并能可靠地加进 / 移出。

进阶还要处理协作约束：**同一项目角色不能重复占用**、**无权限不能改**、**正在干活的 Agent 移出要二次确认**——冲突要说清楚，不能静默失败。

**本任务不做「邀请真人进群」**：群成员 = 当前会话协作名单里的 Agent。

## 用户操作链路

```text
① 打开某个群聊 / 协作会话
      ↓
② 点右上角「⋯」打开「群聊设置」抽屉
      ↓
③ 「群成员（Agent）」：看到本会话 Agent、「来自：某次历史会话」、使用中角标
      ↓
④ 顶栏搜索本会话 Agent（显示匹配 n/共 m）；「+」检索历史会话 Agent 并添加（同上计数；冲突/权限会提示）
      ↓
⑤ 只选中一个 Agent → 下方改项目角色并保存（角色被占用则提示并回读对齐）
      ↓
⑥ 点选 →「移出」：若使用中则确认框 → 确认后回读；取消则不变
      ↓
⑦ 任何失败：界面与服务端对齐，并给出可读错误文案
```

## 数据关系

| 概念 | 含义 | 本轮产品文案 |
|------|------|--------------|
| 群成员 | 当前会话协作名单中的 Agent | 智能体管家、SQL 专家、可视化专家… |
| 来源会话 | Agent 演化 / 沉淀自哪次历史会话 | 如「Q3 销售分析」「库存清洗」 |
| 项目角色 | 协作分工（同会话唯一） | 编排 / 数据 / 画图 / 分析 / 处理 / 建模 |
| 空间角色 | 执行身份 | 执行智能体 |
| 使用中 | 正被当前协作占用 | 角标「使用中」；移出需确认 |
| 管理权限 | Mock 操作者是否可改名单/角色 | 无权限时全拒绝并提示 |

## 边界

- **已做（基础）**：列表、检索添加、移出、回读、失败不脏
- **已做（进阶）**：改角色、角色冲突、权限不足、重复绑定提示、使用中移出确认
- **已做（挑战）**：成员搜索（本会话 + 历史候选双通道、匹配计数、规模说明）；详见 `挑战档说明.md`
- **不做**：邀请真人、接真后端、批量导入 / 分页
